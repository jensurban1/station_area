# 역세권 활성화사업 검토 툴

해안건축 도시건축본부에서 내부 검토용으로 제작한 역세권 활성화사업 자동 산정 툴입니다.

## 기능

| 단계 | 내용 |
|---|---|
| Step 1 입지요건 | 역 이름 검색 → 중심지 체계 자동 판별 → 역세권 반경(250m/350m) 산출 → 제외 대상 체크 |
| Step 2 대상지요건 | 면적·도로·노후도 요건 자동 판정 |
| Step 3 용도·용적률 | 최대 변경 가능 용도지역 산출 → 기준·상한·증가용적률 계산 → 인센티브(관광숙박·ZEB·창의혁신·공개공지) 산정 |
| Step 4 공공기여 | 공공기여율·면적·개략 금액 자동 산정 |
| Step 5 종합결과 | 사업 추진 가능 여부 판정 → 시나리오 비교 → 예상 이슈 목록 → 사업 일정 |

## 적용 기준

- **역세권 활성화사업 운영기준** (2025.10.31 최종 개정)
- **역세권 범위 참고자료** (서울시 도시공간전략과, 2025.08 기준)
- **서울특별시 지구단위계획 수립기준** (공개공지 인센티브 산정식)

## GitHub Pages 배포 방법

1. 이 저장소를 Fork 또는 새 저장소에 업로드
2. `Settings` → `Pages` → `Source: Deploy from a branch` → `main` 브랜치 `/root` 선택
3. 저장 후 잠시 기다리면 `https://{username}.github.io/{repo-name}/` 으로 접속 가능
